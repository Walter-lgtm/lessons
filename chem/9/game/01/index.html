Собери вещества: катион + анион = нейтральная группа

Правила игры

  1. Катионы (+) и анионы (−) падают в стакан.
  2. Если группа ионов соприкасается и суммарный заряд равен 0 — происходит реакция.
  3. Каждый ион должен быть «нейтрализован» соседями противоположного заряда.
  4. Осадок и газ дают дополнительные очки.
  5. Стакан не должен заполняться до верха — иначе Game Over.
  6. Управление: кнопки ← → ↓ по бокам экрана, ⏸ — пауза.
